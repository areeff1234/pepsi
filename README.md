# 🥤 Pepsi — Website Iklan Produk

Website iklan produk Pepsi yang modern, responsif, dan interaktif. Dibangun dengan **React + Vite**.

## ✨ Fitur

- 🎬 **Hero Banner Video** — Video background penuh layar
- 📱 **Fully Responsive** — Mobile, Tablet, Desktop
- 🎞️ **Scroll Animations** — Animasi saat scroll ke bawah
- ⏱️ **Countdown Timer** — Timer promo live
- 🛒 **Add to Cart** — Tambah produk ke keranjang
- 🍔 **Hamburger Menu** — Menu mobile yang smooth

## 🚀 Cara Jalankan

```bash
npm install
npm run dev
```

Buka: http://localhost:5175

## 🛠️ Tech Stack

- React 18
- Vite
- CSS External (per komponen)
- Font Awesome Icons
- Google Fonts (Poppins)
